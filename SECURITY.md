# Security policy

## Supported versions

NovaGraph is experimental. There is currently no production-supported release or guaranteed security support window. Use the latest reviewed source for evaluation, retain backups, and consult the [compatibility and limitations guide](docs-web/content/compatibility.md).

## Reporting a vulnerability

Use the public repository's **Security → Report a vulnerability** form to report privately. Include the affected revision, a minimal reproduction using synthetic data, impact, and relevant environment details. Do not include credentials, personal data, or a real database in the report.

If private reporting is unavailable, open an issue that only requests a private reporting channel, without technical vulnerability details. Do not disclose exploit details publicly while arranging private contact.

Maintainers must enable and test private vulnerability reporting before the first public release. No response-time or remediation-time guarantee is currently offered.
